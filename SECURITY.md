# Security

Please report vulnerabilities privately. Use GitHub's [private vulnerability reporting](https://github.com/humanlayer/humanlayer/security/advisories/new), or email support@humanlayer.dev with "security" in the subject.

Include what you found, how to reproduce it, and what it lets someone do. We'll confirm we got it and keep you posted until it's fixed.

Please don't open a public issue or pull request for a vulnerability until we've shipped a fix.

This covers the code in this repo and HumanLayer Cloud. For a self-hosted install, report problems in this code here; problems in your own setup are yours to fix.
