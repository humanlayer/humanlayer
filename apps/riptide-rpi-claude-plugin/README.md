# Riptide RPI Plugin

Research-Plan-Implement workflow for Linear tickets with Claude Code.

## Installation

From the root of your clone of humanlayer/humanlayer:

```
/plugin marketplace add ./apps/riptide-rpi-claude-plugin
/plugin install riptide-rpi@humanlayer-riptide-rpi
```

Claude Code loads the plugin from your clone, so after a `git pull` run `/reload-plugins` or restart Claude Code.

## Test Installation

Say "set up rpi" to verify the plugin is working and validate prerequisites.
