# HumanLayer Docs

Choose a page by what you need to do. Each section serves a different reader goal.

## Tutorials

Tutorials teach you through a guided, successful task.

- [Run your first HumanLayer task](/tutorials/first-session): install the macOS app and run one small task with Claude Code.
- [Run a task on a remote daemon](/tutorials/remote-daemon): connect a remote host with a launch token and select it for one task.

## How-to guides

How-to guides help you complete a specific task.

- [Choose and run a workflow](/guide/skills-workflows): choose a workflow, review each phase, and finish the task.
- [Set up a workspace](/guide/workspaces): configure where HumanLayer creates task worktrees with `workspace.json` and `workspace.local.json`.
- [Run sessions in automations](/guide/automation-sessions): run one Cloud-visible coding session from CI or any automation environment, with a GitHub Actions example.
- [Run a remote daemon](/guide/remote-daemons): run HumanLayer on Linux, Windows, a remote machine, or a private-network host.
- [Use remote hosts only](/guide/local-daemon): turn off the desktop app's local daemon and run sessions on remote hosts.
- [Set up Codex CLI](/guide/codex): authenticate Codex and select it as a provider.
- [Run Claude through AWS Bedrock](/guide/bedrock): configure Bedrock and pin the models that sessions use.
- [Create tasks from GitHub issues](/guide/github-integration): connect repositories and use source-issue artifact links.
- [Send task updates to Slack](/guide/slack-integration): send selected HumanLayer events to Slack channels.
- [Run workflows from Linear issues](/guide/linear-integration): create tasks, prepare RPI states, and link work back to Linear.
- [Create tasks from Jira tickets](/guide/jira-integration): connect Jira and start work from a ticket.
