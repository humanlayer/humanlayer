every create- has an iterate-
  • create-* writes a new artifact
  • iterate-* revises it in place, keeping the filename
  • e.g. /rpi:iterate-prd, /rpi:iterate-tdd
anytime
  • /rpi:review-artifact-comments — reply to doc comments
  • /rpi:setup-worktree — create the task worktree
  • /rpi:ci-commit — focused commits
why plan at all
  • the agent builds in minutes; review still takes hours
  • 30 minutes of planning saves hours of review
  • every skipped decision gets made during code review instead
